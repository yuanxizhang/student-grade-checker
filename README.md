# student-grade-checker

A lightweight, responsive web application that instantly converts numerical grades (0-100) into standard letter grades (A-F). 

## Features

- **Instant Conversion:** Converts grades in real-time as you type.
- **Input Validation:** Prevents invalid percentages (e.g., negative numbers or scores over 100).
- **Responsive Design:** Works seamlessly on desktops, tablets, and mobile devices.
- **Visual Feedback:** Color-coded results based on the achieved grade (e.g., green for passing, red for failing).

## Grade Scale Used

The application utilizes the following standard grading scale:

| Numerical Range | Letter Grade |
| :--- | :--- |
| 90 - 100 | A |
| 80 - 89 | B |
| 70 - 79 | C |
| 60 - 69 | D |
| Below 60 | F |

## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Hosting:** GitHub Pages

## Getting Started

Follow these steps to run the project locally on your machine.

### Prerequisites

You only need a modern web browser (like Chrome, Firefox, or Safari) installed.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yuanxizhang/student-grade-checker
   ```

2. **Navigate into the project directory:**
   ```bash
   cd student-grade-checker
   ```

3. **Open the application:**
   Double-click the `index.html` file to launch it directly in your preferred browser.
